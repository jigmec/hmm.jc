For Tsagay — GitHub Pages website

Upload index.html and the images/ and audio/ folders into the ROOT of your GitHub repository (not the ZIP and not the outer folder). In Settings > Pages choose Deploy from a branch > main > /(root).

This is a public GitHub Pages site: the purple code is a playful surprise, not actual access control. The personal voice recording and photos are publicly accessible to anyone who finds their URLs.

The song opens an official-search page instead of bundling copyrighted audio.
